Zálohování

Automatické zálohování zatím není součástí aplikace. Zálohu databáze a souborů je třeba dělat ručně (Docker):

docker compose exec -T db pg_dump -U businessmanager businessmanager > zaloha.sql
docker run --rm -v businessmanager_media:/m -v "%cd%":/b alpine tar czf /b/media.tgz -C /m .

Obnova a další postupy jsou v README.
