{% comment %} Prohlížeč fotek a dokumentů. BMV.open(soubory, i[, j]) otevře okno přes celou obrazovku (j = druhý soubor k porovnání vedle sebe), BMV.mount(prvek, soubor) vloží náhled do libovolného prvku (boční náhled v detailu zařízení). Soubor = {title, kind: img|pdf|html|jiný, url, dl}. Fotka se přibližuje kolečkem myši, posouvá tažením, dvojklik ji vrátí na celou velikost. PDF a doklady mají vlastní posuvník prohlížeče. {% endcomment %}
