# Složka pro volitelné moduly

Sem se kopírují volitelné moduly z repozitáře https://github.com/MajkyyQ/BusinessManager-moduly, každý jako vlastní podsložka (např. `moduly/email/apps.py`).
Po zkopírování spusťte `aktualizace.bat` nebo `docker compose up -d --build`. Moduly se do Gitu aplikace neukládají.

Podrobný návod: [docs/11-moduly.md](../docs/11-moduly.md).
